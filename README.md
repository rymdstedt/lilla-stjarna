# Lilla stjärna

En svensk, responsiv sagosida som fungerar som en statisk webbplats och kan publiceras gratis med GitHub Pages.

## Publicera med GitHub Pages

1. Skapa ett GitHub-repo och lägg upp `index.html`, `styles.css`, `app.js` och `README.md` i roten.
2. Öppna repo-inställningarna → **Pages**.
3. Under **Build and deployment**, välj **Deploy from a branch**, välj `main` och `/ (root)`, och spara.
4. GitHub visar adressen när publiceringen är klar.

Inga API-nycklar, serverdelar eller betaltjänster behövs. Sagor skapas i webbläsaren och sparas lokalt på enheten. Uppläsningen använder webbläsarens inbyggda talmotor och installerade röster; röstutbud och ljudkvalitet skiljer sig mellan enheter. Enheten kan vid behov hämta typsnitt från Google Fonts. Sidan fungerar även utan dem.
